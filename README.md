# HDB Resale Data Engineering Assessment

This repository will contain a reproducible Python pipeline for HDB resale
transactions from January 2012 through December 2017, a data profiling report,
and AWS ingestion and analysis architecture diagrams.

The source datasets are published in the [HDB Resale Flat Prices collection](https://data.gov.sg/collections/189/view).

Implementation and run instructions will be added as the assessment progresses.
